# DSA4212 Assignment: Bayesian Optimisation vs CMA-ES

Topic: Bayesian Optimisation vs Evolutionary Strategies
(https://alexxthiery.github.io/teaching/bo-vs-es/bo-vs-es.html)

## Research question
Can Bayesian optimisation and CMA-ES find and exploit the important directions
of a problem when those directions are not aligned with the coordinate axes
(rotation and low effective dimension), and does this explain when each method wins?

## Environment and dependencies
Python 3.11+, CPU only.

    pip install -r requirements.txt

## Repository layout
- authors.md: names and student numbers
- requirements.txt: Python libraries
- report/: LaTeX source of the report, bibliography and figures
- code/: experiment and plotting code
- configs/: one config file per experiment
- results/: saved numerical results, one folder per experiment

## Data
No external data. All test functions are synthetic and generated by the code.
